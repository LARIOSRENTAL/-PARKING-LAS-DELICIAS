# Puesta en marcha contable: 1 de noviembre de 2026

Propuesta pendiente de autorización y despliegue. No aplicar automáticamente ni fusionar esta rama sin autorización para cambiar la base de datos de producción.

La migración conserva el histórico de pruebas anterior al 1/11/2026, hora de Madrid. Los documentos posteriores usan contadores independientes por serie y año: ONH/OTH/OFH para rotación, OND/OTD/OFD para estancias y OFM para abonos mensuales. Ejemplo: OFD 260001. Los pagos con tarjeta generan ticket; el efectivo sin impresión utiliza ON. Añadir datos fiscales a un OTH/OTD conserva su identidad y no duplica el cobro. La factura completa solicitada durante el cobro utiliza OF. Las exportaciones separan serie, número y fecha.

Desde esa fecha se rechaza el cierre de turno con diferencia de caja distinta de cero. Se conserva la entrada original de la reserva al dar entrada.

Los dos abonados que deben recibir solamente recibo mensual siguen sin identificar. La lista de excepciones queda vacía: no se cambia el régimen de ningún abonado por inferencia. La ficha incorpora una opción explícita para configurarlos cuando se confirmen sus nombres.
